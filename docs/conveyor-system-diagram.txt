================================================================================
                              LEGEND
================================================================================

  Cx   = Conveyor number (1-30)
  Sx   = Stop Sensor (detects items at stop position)
  Mx   = Motor (drives the conveyor belt)
  ───▶ = Material flow direction (left to right)

================================================================================
                         SYSTEM CHARACTERISTICS
================================================================================

  • Each line operates independently with its own shift register simulation
  • All lines share the same GlobalRelease and OperatingMode signals
  • Each conveyor has:
    - Individual motor with acceleration/deceleration control
    - Stop sensor for item detection
    - Stop position management
  
  • Simulation parameters:
    - Shift register: 70 positions (7 seconds @ 100ms intervals)
    - Package generation: Every 2 seconds
    - Sensor spacing: 0.7 seconds (7 positions)
    - Conveyor speed: 1.5 m/s
    - Acceleration/Deceleration: 1.0 m/s²
